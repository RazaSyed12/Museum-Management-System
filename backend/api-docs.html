Swap a refresh token for a new session

Call this when the access token expires. The response contains a new access token AND a new refresh token; the old refresh token stops working, so the frontend must save the new one every time.

Request Body schema: application/json
required
refresh_token
required
string

The refresh_token from the latest sign-in or refresh

Responses

    • "expires_at": 0
    }

Collections

List collections

Public. Without a token only published collections are returned. With a staff token, drafts and archived collections are included too.

Authorizations:
NonebearerAuth
query Parameters
q
string <= 100 characters

Only collections whose name contains this text (case-insensitive)

featured
string
Enum: "true" "false"

Only featured (true) or non-featured (false) collections

limit
integer [ 1 .. 100 ]
Default: 20

Page size

offset
integer >= 0
Default: 0

How many collections to skip

Responses
