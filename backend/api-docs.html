Categories

List categories

Public. Feeds the onboarding interest picker, category filters and staff forms. Without a token (or with a non-staff token) only active categories are returned. With a staff token, deactivated categories are included too. Always the full list, sorted by name (no paging).

Authorizations:
NonebearerAuth
query Parameters
top_level
string
Enum: "true" "false"

true = only categories with no parent (what the onboarding page shows); false = only sub-categories; omit for all.

Events

Public. Without a token, draft events are hidden (scheduled and cancelled ones are shown). With a staff token, drafts are included.

NonebearerAuth
query Parameters
when
string
Default: "upcoming"
Enum: "upcoming" "past" "all"

upcoming = hasn't ended yet, soonest first (default); past = already ended, most recent first; all = everything, soonest first

q
string <= 100 characters

Only events whose name contains this text (case-insensitive)

category_id
string <uuid>

Only events in this category or one of its sub-categories

collection_id
string <uuid>

Only events that showcase this collection

status
string
Enum: "draft" "scheduled" "cancelled"

Only events with this status (draft is only visible to staff)

limit
integer [ 1 .. 100 ]
Default: 20
offset
integer >= 0
Default: 0

Recommendations

Recommended events and collections

Public. Feeds the "Recommended for you" row on the Home page; it does not restrict browsing (GET /events and GET /collections still list everything). Signed in with interest picks: items matching the picks (including their sub-categories) come first, most matches first, then the list is topped up with other items. Guests and users without picks get the same list without the personal part. Only scheduled, not-yet-ended events and published collections are recommended.

NonebearerAuth
